# Creative Nest by Diya 🎨

**The home of heartfelt gifting.**

🌐 **[Click here to view the live website!](https://shlokdesai2210.github.io/creative-nest-website/)**

A beautiful product showcase website for Creative Nest by Diya — featuring handmade, personalised gifts with WhatsApp-based ordering.

## 🌟 Features

- 📱 Mobile-first responsive design
- 💬 WhatsApp integration for ordering & inquiries
- 🏷️ "Sold Out" badges for out-of-stock items
- 🔍 Category filtering and product sorting
- ⚡ Fast static site (Next.js + Tailwind CSS)
- 🆓 Free hosting on GitHub Pages

## 🛍️ Product Categories

- Customised Hampers
- Bouquets
- DIY Plates
- Name Plates
- Frames
- Photo Customised

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📦 Tech Stack

- **Next.js 14** — React framework
- **Tailwind CSS** — Utility-first CSS
- **TypeScript** — Type safety
- **Lucide React** — Beautiful icons
- **GitHub Pages** — Free hosting
